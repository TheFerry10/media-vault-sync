Before modifying or reviewing code, follow the Python style, architecture,
safety, and verification rules in `.github/copilot-instructions.md`.

Issues are tracked in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

Use the default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.
